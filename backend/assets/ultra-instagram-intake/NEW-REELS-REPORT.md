## Shared acceptance checklist

- [x] Ten-second, 16:9 landscape written shot plan.
- [x] Bride image is the sole face-identity authority; premium bridal styling, not casual clothing.
- [x] All dress views describe one exact garment and matching dupatta.
- [x] Attached jewellery sheet controls jewellery design.
- [x] Strict mannequin exclusion, including white/plastic abdomen patches; exposed waist must be human skin.
- [x] Source video is NOT attached to the generation model.
- [x] Original first-ten-second audio saved for backend finishing, not recreated by the model.
- [x] Recognizable source-frame thumbnail; sideways source content corrected upright.
- [x] Final prompts stay below the owner's 4,000-character target.
- [ ] Owner generation and visual acceptance of face, dress, jewellery and motion.

## Analysis and verification scope

The first ten seconds were inspected with chronological quarter-second frame contact sheets and detected-cut frames. These are frame-derived shot studies, not a claim of continuous playback or song identification. Shot timing is approximate. Landscape surroundings are adapted from portrait/sideways sources; exact motion or 100% identity cannot be guaranteed by a prompt.

Each final prompt combines `bridal-reference-rules-v2.txt` with that reel folder's `shots.txt`, normalized to LF line endings. The template registry validates its final character count. The 4,000 target is a project constraint, not a newly verified universal provider limit.

Offline tests cover routing, prompt preservation, image bundles, source-video exclusion, and audio merging into a local ten-second landscape test clip. No paid provider generation was submitted for these seven templates.
