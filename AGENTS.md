# Project prompt workflow

For Budget Speed bridal prompt creation, reference-video analysis or template integration, read `BUDGET_SPEED_PROMPT_WORKFLOW.md` before working. It records the user's agreed reference roles, dynamic bride/dress inputs, chronological scene stills, silent generation with original music, and live integration verification.

For Premium (Wan 3.0 Prime) templates built from Instagram/reference videos, read `PREMIUM_WAN_PROMPT_WORKFLOW.md` before working. It records the 5,000-character Wan prompt limit, video-reference character replacement, dynamic bride/dress roles, and the database-jewellery-or-minimal rule.

Apply this workflow to Budget Speed. Budget Balance uses its separately configured source-video reference route; do not silently change Balance to photos-only. Follow the user's latest explicit instructions when they change the workflow or request manual review before integration.
