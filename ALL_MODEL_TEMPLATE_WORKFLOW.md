# Shared bridal template library

Every reviewed source has one template identity and a moment thumbnail. Budget Speed and Premium Speed use chronological scene screenshots. Budget Balance and Premium Balance use a ten-second source-motion reference, retaining the selected defining action and camera progression.

Read BUDGET_SPEED_PROMPT_WORKFLOW.md for identity, garment, emotion, scene study, music and quality acceptance rules. The attached bride photograph defines identity. One full-front garment photograph is required; optional detail, side and rear views supplement it. Sources with several models or outfit changes are adapted to one customer bride and one selected garment throughout.

For long sources, retain the original download locally. Archive the first clear frame of each meaningful shot, including all the surroundings. Build chronological boards from those frames for the ingredient limit. The ten-second motion reference compresses repeated holds using the shot plan; it does not contain an advertising end card. Source timestamp and output timestamp are recorded separately in each prompt.

Generate silent visuals and add the saved source audio afterward. Default audio offset is zero. Speed attaches actual scene-image assets with role mapping. Balance attaches the prepared source clip and the customer identity/garment evidence; scene stills are retained for inspection and card artwork.

Premium templates are registered even when the provider connection is unavailable. Registration is not verification of generation or motion control. Premium generation remains gated until the live MCP connection, model and combined image/video inputs are confirmed. Do not substitute the paid API as a fallback or claim exact motion copying without a successful capability test.

All outputs require manual face and garment review. A prompt or source reference cannot guarantee identical likeness or universal policy acceptance. Romantic scenes should describe the intended natural adult interaction clearly; provider rejections should be reported with the correct submitted request, not a previous failed tile.

Instagram intake uses the official yt-dlp release, with no cookies, login or private-content access. The ten links supplied on October 14, 2026 are stored in backend/assets/instagram-intake.txt. Source downloads remain in backend/assets/instagram-intake, alongside provenance metadata. Prompts and media are in numbered budget-speed-batch directories.
